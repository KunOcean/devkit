# DevKit 规范与工作流提示词

## 这个技能是什么

从 DevKit 网页版单文件应用（`deepseek_A1_V_Φ7_CN.html`）中抽取的两部分提示词资产：

| 文件 | 内容 | 体量 |
|------|------|------|
| `references/spec-prompt.md` | 《规范提示词》全文——开发本项目时必须遵守的协作流程、版本架构、代码完整性等硬性规范 | 约 25 KB |
| `references/prompt-templates.md` | 22 个工作流提示词模板（版本规划、安全审计、完全重写……） | 约 35 KB |

## 何时使用

- 用户要求按 DevKit 规范产出代码（含版本号推导、版权注释块、双版本派生）
- 用户点名某个工作流步骤（如"帮我做一次安全审计""推导下一版版本号"），需要套用对应模板
- 用户要求绘制版本结构图（Mermaid 整略图 / Mermaid 完整图 / HTML 版本结构图）
- 用户要求"复制规范提示词"

## 使用方式

1. **先判断类别**：规范类 → 读 `references/spec-prompt.md`；模板类 → 读 `references/prompt-templates.md`
2. **只读需要的那个文件**。两个都读约 60 KB，会无谓占用上下文
3. **模板类**：按 `label` 或 `category` 定位模板，把 `{inspiration}` 替换为需求、`{code}` 替换为代码，然后原样输出替换后的完整提示词——**不要自行改写措辞、不要精简**
4. **规范类**：
   - 用户要"按规范执行" → 把规范作为本次对话的约束实际执行
   - 用户要"复制规范" → 原样输出全文，不做删改

## 不可违反的要点（摘录，完整内容见 references）

- **版本号**：四层基础（分支代号 / 罗马数字 / Φ+数字 / 英文标识）＋ 循环扩展（`B1 → I → Ψ1 → 英文标识 → C1 …`）；语言变体共享主干版本号，仅在末尾追加 `_CN` / `_GLOBAL`
- **双版本派生**：落后版一律以领先版同一主干版本为源翻译派生；禁止"基于自己上一版独立迭代"；禁止全文重译
- **代码完整性**：输出完整代码时不得省略、不得使用占位符；输出完毕后附「确认完整」标记
- **协作流程**：数字选项清单必须压轴，选项前若有建议须用 `---` 分隔
- **已废弃概念**：智能应用引擎 / AI 输出指令协议、"指令修改版"选项、落后版独立迭代模式——不得恢复
